# Kosolo

Kosolo 应用主页、隐私政策与服务条款（GitHub Pages）。

## 页面地址

启用 GitHub Pages（Source: Deploy from a branch → `main` / `/ (root)`）后：

- 应用主页：https://chenzhg33.github.io/kosolo-app/
- 隐私政策：https://chenzhg33.github.io/kosolo-app/privacy.html
- 服务条款：https://chenzhg33.github.io/kosolo-app/terms.html

## Play Console 填写

1. 左侧「品牌」→ 填写应用主页、隐私政策与服务条款（Terms of Service）链接
2. 「授权域名」填写：`chenzhg33.github.io`
3. 保存后返回「受众」，「发布应用」按钮应可用

请勿删除本仓库或关闭 GitHub Pages，否则链接失效会影响合规状态。
